# 01-03 残余风险与跨任务边界

限定成果待独立验收，G1未过，不改V2.1为完成，不启动01-04。

- 部署必须同步配置AI_SERVICE_TOKEN与app.ai-service-token、AI_CALLBACK_BASE_URL与app.internal-callback-base-url、AI_STORAGE_ROOT与共享存储。实例配置没有被读取或重写；旧启动方式未配这些新参数将fail-closed。/health最小公开不证明私有操作已配置可用。生产TLS、网络ACL、秘密生成/轮换/集中管理仍需01-04及部署验收。
- 静态服务秘密可能重放，泄露者可按服务权限分析/取消；不能把任务级回调grant称完整服务防重放。grant仅当前单JVM调用、2小时、进程重启失效，多实例/迟到/乱序/重复进度、取消竞态、幂等与attempt状态仍属01-05/06。非持久化grant不构成完整analysis-run-v1。
- TaskService保持原状态/事务。AiClient取消投递失败现在抛出脱敏异常，原CANCEL_REQUESTED事务可能回滚；没有承诺投递重试/异步取消完成。分析读超时上限2小时，长任务/取消时限与吞吐尚无生产验证。真实任务最终状态验证属于后续状态机，桥接仅测试进度写入。
- 路径验证不是原子文件打开，依赖受控ACL；恶意并发重解析点置换/硬链接竞态未动态验收。Python预存硬链接拒绝已测，但不能据此声称全系统硬链接风险消失。Windows符号链接创建受限SKIP，需要本机具备权限补验；junction不是替代PASS。
- HTTP非mock安全停机503是本轮有意边界：真实算法尚未贯通，不尝试安装/下载或回退伪成功。原底层函数4项历史fallback测试保留，因此不能将它们解释成所有CLI也已禁止fallback。公开安全边界是鉴权HTTP入口；不为任意Python本机代码提供沙箱。
- 不支持DNS目标及环境HTTP代理，包含原先依赖服务名DNS的部署；需明确配置固定IP，未来变更需独立审查。合法目标返回重定向会中止；可能留下合法任务工作目录，不访问Location。认证/参数拒绝在写入前，运行期网络故障和拒绝请求的副作用边界不同。
- 01-01/02的资源授权和媒体规则保留，REFEREE原有产品导航限制、JWT即时全局撤销、TLS/70分钟/高并发/多浏览器、默认管理员/实例旧秘密、数据授权/异盘灾备与真实YOLO/ByteTrack等继续开放。没有对外发布、真实DB或原视频操作。
