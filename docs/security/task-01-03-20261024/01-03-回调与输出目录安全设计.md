# 01-03 回调与输出目录安全设计

2026-10-24，V2.1限定任务；不实现完整analysis-run-v1或01-05/06状态机。

独立AI入站服务凭据由AI_SERVICE_TOKEN与app.ai-service-token提供，至少32字符，要求运维使用随机ASCII秘密；请求头X-AI-Service-Token，不在URL/JSON/日志。FastAPI除最小health外均先鉴权再解析body；普通JWT、媒体Cookie、localhost来源本身都不提供内部身份。服务凭据是静态共享秘密，不自带有效期/抗重放，TLS与轮换策略仍需部署验收。本轮未采用时效请求签名，因此“过期签名/一次性重放拒绝”不作为已实现能力。

回调与入站服务密钥分离：Java在每次同步HTTP分析前为taskId生成256bit随机grant，经X-Callback-Token传AI，AI仅请求ContextVar持有；后端X-Internal-Token现在仅接受此任务当前grant。有效期2小时、调用finally撤销；相同task重新issue使旧grant失效；旧调用revoke不能撤掉新grant。重启无grant而失败关闭。测试包含跨任务、旧调用、撤销和模拟时钟过期。同一有效grant内可多次合法进度更新，不宣称序号防重放、并发任务幂等、跨实例授权同步、持久化attemptId或乱序回调状态机。

唯一回调目标：AI_CALLBACK_BASE_URL / app.internal-callback-base-url所配置的http(s)字面IP与端口，加/api/internal/tasks/{正整数}/progress。配置localhost会明确映射127.0.0.1；其他DNS主机拒绝，不引入DNS解析信任窗口。原JSON callbackUrl必须为空或与规范目标逐字相同；其他scheme、host、端口、userinfo、编码、query/fragment/path变体均先拒绝，不试探公网或私网。旧Javacallback参数完全忽略，不与固定配置混合，后续可移除废弃签名。Python及Java客户端禁代理、禁重定向，合法目标若302返回则失败并不访问Location。重定向运行失败前可能已创建合法task目录/向固定回调发出一次请求，不把它说成“从未联网/写目录”。

AI_STORAGE_ROOT必须显式给定已有绝对目录，禁止读实例配置推断；Java采用既有app.storage-root。输入仅root/uploads下现存普通文件，输出必须严格等于root/tasks/task-ID，允许合法相对目录及Windows大小写等价。拒绝绝对越界、..、编码/双编码、UNC/设备路径、ADS、短名~、尾点/空格、非法控制/文件字符、根前缀相似目录、跨task/额外子路径。验证阶段不mkdir；目标未存在也先检查现存祖先；存在时检查所有后代，拒绝symlink、Windows重解析点/junction及多链接普通文件，避免固定结果文件写入链接目标。算法内固定子目录/文件名留在此根。Java也预检输入/输出再发请求，AI独立执行写边界，未误用01-02只读校验来接受任意待建目录。

所有路径检查到真实打开仍有TOCTOU窗口；必须限制存储ACL与同权限不可信写入，不能宣称抗恶意并发FS进程。AI持有服务凭据即被视为可信服务，路径绑定是taskId→固定目录，不在AI复制用户/任务数据库；后端仍负责DB资源授权。可信CLI直接函数调用不是不可信网络入口的沙箱，原算法fixture/脚本可写其本机参数，未作为服务对外开放。

错误：缺/错服务凭据401，缺安全配置503，非法请求/URL/目录422，非mock503 REAL_PIPELINE_UNAVAILABLE，固定回调不可用/重定向502，取消409，其他分析错误500且固定结构化代码。Pydantic默认反射input已替换为通用INVALID_REQUEST，不把令牌/文件路径回显。Spring内部无效身份401、合法身份非法进度400。健康不提供模型路径，内部callback message不传原模型note。

部署迁移必须同时配置双方服务秘密、相同规范回调origin和共享存储根；本轮仅合成配置，不生成或修改实例secret。原app.internal-token不再是回调通行证。真实模型未贯通，HTTP非mock保守拒绝；直接4项底层fallback fixture保持，不伪造真实成功。服务间成功Mock结构与已有前端接口保持，前端未修改。
