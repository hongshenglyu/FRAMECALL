# 01-02 兼容与残余风险

V2.0限定任务，建议独立审查，不自行写V2.1或G1通过。

旧/api/files?path客户端有意停用，所有使用处随当前前端同时升级；没有不鉴权兼容后门。旧授权DTO originalPath/keyframePath/clipPath/outputDir等字段为兼容保留，UI媒体URL和新PDF不再使用/打印绝对路径；这不是整个API信息最小化改造。旧含路径的历史PDF没有被回写。媒体类型收紧到浏览器图像/MP4/WebM，其他视频格式没有转码承诺；.txt占位片段404。

原11项Task/Event/Review及PDF回归通过。两Controller/原授权测试保持字节，ResourceAccessService只抽取Video谓词、添加requireVideo；无DB迁移/历史数据重绑/复核生命周期变化。PDF视觉排版、旧截图显示兼容性未重新完整验收。VideoAnnotationPage继续ADMIN专属，REFEREE自身视频能经受控URL原生播放但没有新加管理页导航；是否扩大产品入口属于后续明确需求。

下载入口补充盘点：AnnotationController还存在标注JSON与CSV附件导出，既有类级ADMIN-only及Bearer保留；它们不是原视频/关键帧读取，也不接受媒体Cookie。正常导出由原Smoke覆盖，其异常路径/非法Range/角色组合没有在01-02新增逐项运行，矩阵明确静态依据，不宣称这些既有附件接口已做本轮全新加固。
