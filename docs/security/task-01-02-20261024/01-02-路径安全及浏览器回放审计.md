# 01-02 路径安全及浏览器回放审计

身份→DB Video/Task/Event→owner/assigned/current ADMIN→受控路径→元数据→资源流。客户端不能再指定path；B即使知道ID/旧路径也不触碰文件解析。缺关系/缺owner拒绝包括ADMIN，沿用01-01；未认证401，越权/不存在/非法路径404，避免区分存在性；合法主体非法Range416可含已授权资源长度。

路径不是字符串前缀：先按路径组件检查词法root包含，再NOFOLLOW属性拒绝symbolicLink/isOther重解析点，解析toRealPath后再用Path.startsWith检查真实root。拒绝百分号编码/双编码、NUL、..和.组件、UNC/设备路径、异常盘符/ADS冒号、短名~、尾点/尾空格和根前缀相似目录；Windows大小写差异与受控storage相对别名可以正常访问。原始合法Windows绝对路径只来自已授权持久化记录，不接受URL中的客户端完整路径。事件派生媒体绑定tasks/task-ID，或者明确等于所属视频原件，不能借其他任务文件。

根目录与各后代组件检查后再打开Resource仍存在操作系统并发置换窗口，不声称抵抗拥有文件系统写权限的恶意本地用户。必须保护存储目录ACL；Windows硬链接/并发重解析点切换未动态验收。现有AI写路径入口由后续01-03处理，不能据本轮推断整个写入面安全。PDF授权后读取关键帧也复用边界检查，越界图像不嵌入，越界输出拒绝；不打印媒体绝对路径。

Cookie桥接方案：Bearer认证的POST设置HttpOnly/Path=/api/files/SameSite=Strict，request.isSecure时Secure，Max-Age8小时但JWT原exp不刷新；GET/HEAD /api/files才接受Cookie，明确Authorization头优先，坏Bearer不回退Cookie。每次查DB enabled/role/owner/assigned；过期/禁用401，降权/撤指派/归属改变404。Cookie不参与其他API/写操作，不能借它执行业务CSRF；同源页面无需CORS凭据，未开放匿名预检、跨源Cookie或匿名fallback。

取舍：短授权URL有复制泄露、日志及续期成本；认证代理额外增加部署和密钥管理；Fetch+Blob令长片完整缓冲并破坏原生按需seek；本轮选择限定Cookie和原生Resource Range。Cookie是敏感凭据，不进入URL/报告/截图/日志；既有localStorage Bearer风险、XSS、共享主机/同浏览器多账户标签页的会话隔离并未整体重构。退出只清此浏览器Cookie，不全局撤销复制JWT；退出请求失败明确提示，过期会话退出体验尚未额外验收。

正常GET200、单段/开放/suffix206，Content-Type白名单MP4/WebM/PNG/JPEG/GIF/WebP、Accept-Ranges与Content-Length/Content-Range；非法/多段416且空body，no-store、nosniff。HTML/SVG/.txt不作为媒体提供，旧Mock文本不是可播片段。Resource按范围写出，不以byte[]整体缓存或巨型Blob播放。HEAD真实HTTP无body；OPTIONS未认证拒绝。

浏览器使用Chrome生产构建、实际Spring随机端口、合成H.264 MP4。播放时钟前进、seek到8秒/5秒后暂停、原生206及刷新图片通过；截图只含合成账户/媒体。视频标注ADMIN导航保持，A测试原生video由测试加入页面，不能把所有角色的产品导航说成已完整开放。完整事实见browser-result.json，HTTP/单测/浏览器检查有重叠，不把数量相加当独立实验。

部署HTTPS必须使request.isSecure真实可靠；本轮仅本机HTTP与Mock secure属性，TLS终结代理/跨域/多浏览器/70分钟稳定性NOT_RUN。文件符号链接NOT_RUN；junction的实测拒绝是替代证据，不是文件符号链接覆盖声明。
