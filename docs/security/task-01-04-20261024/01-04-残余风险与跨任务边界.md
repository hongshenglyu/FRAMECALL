# 01-04 残余风险与跨任务边界

本轮默认/生产代码不再自动建可预测口令账户；不能由此认定存量真实账户已安全。实际业务数据库、默认账户是否仍存在及其口令均未读取或修改。真实管理员轮换、生产秘密配置、历史泄露与备份清理需本人在受控维护流程处理，不能在聊天提供秘密。

部署有兼容变更：所有profile要求新的FRAMECALL安全键，不再隐式用旧app.*；缺值启动失败。Maven不再携带两实例YAML；端口/上传限制/JPA等非秘密旧设置须显式外置，完整生产部署与真实MySQL未验收。当前安全键样例全部空值，不能直接复制当可运行配置。旧target/Jar/历史文档和受保护备份未自动清理，旧凭据未撤销的风险仍开放。

demo不自动生成固定演示账户，只有唯一demo+明确内存隔离及授权初始化才能建立测试提供的随机账户。bootstrap遇已有用户失败，而不是自动修复账号；初始化成功应关闭开关。多进程同时空库初始化不是本轮已验证的一次性分布式操作，生产初始化需维护窗口和单实例控制。

JWT更严格要求HS256/JWT和未来exp；本项目既有合法签发兼容，外部旧token若无这些字段会被拒。轮换JWT会使旧JWT/媒体Cookie无效，需重新登录。AI秘密质量规则收紧，旧短值/占位值不再可用；静态服务密钥抗重放、TLS/代理、多实例、grant持久化和取消/重试竞态仍不解决。

01-01/02/03授权/媒体/回调规则保持，新Smoke仍验证原业务意图。Windows文件符号链接动态测试仍SKIP；长片、全浏览器、生产TLS、恶意FS并发、实际回退、正式数据/版权/导师审批、真实模型/视频来源及论文指标NOT_RUN。01-05/06/07与Real/Mock合同实施未执行，G1未放行。
