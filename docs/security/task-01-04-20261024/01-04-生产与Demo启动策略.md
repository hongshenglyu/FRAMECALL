# 01-04 生产与Demo启动策略

2026-10-24。本轮只修改代码和隔离夹具，不执行真实管理员/密钥迁移。

默认、production及development不再创建固定用户名/口令；框架自动用户关闭。全新空库若未明确初始化将没有可登录账户，这是有意安全行为。所有profile都必须提供FRAMECALL_JWT_SECRET、FRAMECALL_AI_SERVICE_TOKEN、FRAMECALL_AI_SERVICE_URL、FRAMECALL_CALLBACK_BASE_URL、FRAMECALL_STORAGE_ROOT、FRAMECALL_DATABASE_URL、FRAMECALL_DB_USERNAME、FRAMECALL_DB_PASSWORD。旧app.jwt-secret/旧datasource默认值没有回退权。

环境处理器在ConfigData加载后、任何DB/StorageService/SchemaMigrator bean前执行。缺失、占位、弱值或非法可信配置抛仅含键名的IllegalStateException，停止启动，不在异常中打印值。新键由操作系统环境/明确外部配置/显式程序参数供应，优先于旧app.*别名；生产不要把秘密放入命令行历史，文档/样例只列键。校验后的映射置于高优先级，JwtService也直接读新JWT键。生产密钥应由本人在受控环境独立随机生成，不能只为满足长度拼凑常见字符串。校验长度/格式/多样性不等于数学证明随机性或未泄露。

签名和内部服务秘密长度32～256、受控ASCII字符、至少12种字符并拒绝常见占位；初始化密码另限72字符以内以符合BCrypt。非内存数据库密码也执行同一强秘密规则。只有显式jdbc:h2:mem可空数据库密码；demo额外要求唯一demo profile及FRAMECALL_DEMO_ISOLATED明确true，拒其他profile混用及文件H2/MySQL。没有任何固定demo密码；只有本人明确提供合成初始凭据时才允许演示账户建立。后端URL/回调仍须01-03允许的固定origin；密钥必须和AI侧AI_SERVICE_TOKEN匹配，回调/根也须和AI_CALLBACK_BASE_URL/AI_STORAGE_ROOT一致，不能用匿名回退换兼容。

首次初始化：本人先确认数据库和备份范围；仅在空账户库显式启用FRAMECALL_BOOTSTRAP_ADMIN与FRAMECALL_BOOTSTRAP_CONFIRMED，安全提供FRAMECALL_BOOTSTRAP_USERNAME/PASSWORD。程序创建一个ADMIN后，请立即关闭初始化开关并清除进程中的一次性口令来源。再次带开关启动遇现有账户会失败，绝不删除、禁用、重设或提升已有用户。用户名唯一/密码哈希仍沿用原规则，角色来自服务端。

现有用户迁移：本轮未读取业务用户，更未轮换真实口令。维护者需要先验证身份/数据库归属与备份，再通过受控管理或数据库运维流程轮换可能沿用旧默认值的账户，保留审计记录，确认合法登录/复核历史关联。当前应用没有独立密码找回/重置API，本轮不新增匿名恢复入口。缺少可靠维护途径时，停止生产变更由本人处理，不能宣称存量账户已经安全。

密钥轮换：在维护窗口更新JWT新键会使旧JWT及媒体Cookie签名失效，用户需重新登录；回调grant/多实例会话与服务密钥同步轮换仍需部署方案。AI静态服务凭据仍没有抗重放能力。不要把真实新值发给ChatGPT或放入报告。

实例YAML未读取值/未改文件，Maven资源排除它们；实际资源goal验证仅复制META-INF/spring.factories。正式部署需由维护者显式提供原本非秘密的端口/上传限制/JPA等外部配置，否则采用Spring默认；完整生产Jar/部署兼容性未验收。旧target、旧Jar、历史文档/备份未自动清理，不代表历史秘密已消失。启动脚本本轮仅审计不运行；在配置不全时新代码安全失败。两操作型smoke/layout工具需要本机显式FRAMECALL_SMOKE_*，仍会操作所指服务，不把它们当隔离回归直接运行。
