## 拟议统一规范

videoTimebase.method为pts或经验证的cfr_index；unknown只能用于legacy/mock，Real时间不可信时FAILED TIMEBASE_INVALID。保存源流索引、原始宽高、rotation、timeBase.num/den、startPts、sourceFps.num/den可空、isVfr、durationMs及duration来源。PTS方法下sourceFps未知仍可有效，不能强填25。所有时间戳有对应视频修订。

规范时间秒 t=(sourcePts-startPts)*timeBase.num/timeBase.den；允许源PTS起点非零，规范时间从所选视频起点零开始。帧索引是原视频呈现顺序的零基decodedFrameIndex；sampleIndex只是采样序号，每条样本必须保存实际decodedFrameIndex和sourcePts，不能由sampleIndex*stride替代事实。requestedStride与actualSelectedFrames分开记录；跳帧、VFR、切镜/断轨均保留映射和原因。

若严格CFR已经证实且PTS不可用，才允许t=decodedFrameIndex*fps.den/fps.num，并记录method=cfr_index、验证依据及误差范围；VFR或FPS未知无PTS时明确失败，不用平均FPS或固定25补时间。所有运算用有理数/足够精度，绝不以浮点帧率串代替原分数。检测框坐标用源分辨率像素，缩放检测须保留变换并映回。

公开timestampMs对非负规范时间采用floor(t*1000+0.5)；start窗口向下取整、end向上取整后再钳制到视频[0,durationMs]。窗口半开[start,end)，必须start<=timestamp<end且end>start；负候选峰值/超过duration的峰值不是靠钳制造有效事件，应拒绝或标记不可用。边界附近剪辑按实际可用过程裁剪并记录truncatedStart/truncatedEnd及actualRange，不谎称完整争抢；是否满足完整性评价由冻结指标判定。

速度delta以相邻实际PTS规范时间差计算秒；delta<=0帧记异常并剔除/失败，不用固定epsilon制造速度。B帧按呈现PTS重排，DTS不是呈现时间；重复/回退PTS和缺失时长的具体解码修复策略OPEN，未批准前Real失败或范围不可用，不静默降级CFR。有限正gap也要记录跟踪中断，不跨断轨算速度。

合成例：VFR PTS=[0,40,87]、timeBase=1/1000，时间为0/40/87ms，delta为40/47ms，绝不变成0/40/80。CFR fps=30000/1001，第100个零基呈现索引约3336.667ms，舍入3337ms，不能按25fps算4000ms。源视频本就只是一段剪辑时以该输入为零点；若已知母视频偏移则另记parentOffsetMs，不混同本地时间。

## 媒体来源与准入

每候选媒体清单含assetId、kind(keyframe/clip)、origin(source_video/illustration/mock/placeholder/legacy_unknown)、inputVideoRevision、attemptId、源PTS/请求和实际时间窗、输出容器/尺寸及校验状态。source_video需可信抽帧/剪辑、可解码校验、源帧/窗对应验证，必要时保存非秘密研究媒体的内容摘要以便复现；本轮不读取/复制媒体或输出真实摘要。扩展名.jpg/.mp4本身不证明真实，文本改名mp4也无效。

事件存在而任一必需媒体缺失/不可播/来源不符，则Real FAILED EVIDENCE_INVALID，不能只给evidenceComplete=true。0事件不生成伪媒体；视频级校验/覆盖清单仍需齐备。历史示意图保留可显示但标illustration，文本片段不提供视频播放器。
