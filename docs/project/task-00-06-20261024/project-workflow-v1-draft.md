## 适用边界与成功标准

每次仅领取一个明确WBS，先写成功标准、前置、验收人及不改范围。保留Vue3/Spring Boot/FastAPI原型；单视角疑似接触筛选与人工赛后复核，不自动判犯规。Mock不能充真实、候选评分不是犯规概率、合法零候选不填虚假事件，真实来源/PTS/媒体遵循经独立批准的合同。本机analysis-run-v1-draft.md目前只是草案，修改它需另起明确授权WBS和兼容决策，不能在其他任务顺手改。

## 八个检查点

## 最小变更与Git

修改前通读文件导出/入口、外部调用方和公共依赖，先登记允许/禁止文件。一个WBS一个可审diff，不跨模块扩张、不重构无关代码；冲突实现显式二选一并说明取舍，废弃候选标待清理，不擅自删除。保持API、schema、PDF来源语义、历史事件和人工复核归属；确需变更时先给兼容/版本/回退设计。

保留baseline/pre-ai-refactor-20261022，不重写HEAD或tag。未来使用独立codex/前缀分支或能定位WBS的提交；复用适合当前checkout，变更工作区需先确认安全。提交说明必须含WBS、实际改动、测试/未测、风险与回退。提交前完成可审内容、秘密/大文件排除与本机真实内容确认，并具备用户本机授权；本轮无提交授权也不创建分支。不执行git clean -fd、破坏性reset、强制checkout、rebase/amend重写或越权推送。

未提交变更本身不等于错误：逐文件分为本WBS、已知前置、未知/他人。已知文档可保留并在交接注明；未知差异停止非必要写入，不覆盖/删除。不得将git status干净当源码与数据库可恢复的证据。原DB/授权录像/模型独立隔离与备份，备份门槛按风险确定；同盘、DPAPI绑定、未恢复演练须明示，不能宣称灾备。

## 证据与验收

证据三级：已验证的本轮原始执行/文件检查；报告级静态分析或历史日志；未经验证/NOT_RUN。保存命令、cwd、解释器/依赖版本、开始结束、退出码、实际/预期、日志、失败警告、输入/输出/配置非秘密修订ID与许可。历史日志必须写原时点，报告不能假装本轮重新执行。哈希只证明字节版本，不证明语义正确、授权或模型成功；秘密配置/私人媒体不以哈希替代授权进入分享包。

Codex自检、ChatGPT二次审查、用户本机确认分别登记人/时间/证据/范围；不得互相代签。P0阻断下一相关实现，P1评估受影响范围并明确责任/期限，P2/P3如放行须由验收者接受残余风险；不得以降低优先级绕过核心来源/权限风险。Real须真实输入→真正关联/评分→可核算输出/真实证据，Mock/Smoke/示例脚本成绩不能列论文成果。未过门槛仅待验收/阻塞，不写已完成。G0须独立放行，本轮交付不是G0通过。

## 单一权威状态与跨窗口

权威交接集合为同一最新修订的计划MD+XLSX+最新验收报告+当前Codex指令，不能依赖模型记忆、旧聊天或旧日志。读取顶部版本和末尾最后有效状态，校对修订ID/时间/任务ID；计划两种格式或验收矛盾时记录冲突并停止状态同步，不擅选某一旧结论。找不到计划时写OPEN并请求明确位置，禁止造一份替代品。

状态仅允许：未开始、进行中、待验收、已完成、阻塞、延期、冻结。通常未开始→进行中→待验收→独立验收后已完成；失败可退回进行中或阻塞并留日志；延期/冻结需计划维护者或用户明确决定，恢复需授权与前置重核。状态不是Git状态，也不是分析任务SUCCEEDED。

经授权更新下一版计划时同步主任务H列状态、I列完成比例、N列最后更新、O列阻塞，并同步执行日志、风险与关口。先核实际工作表/列头/公式和WBS唯一行；不得按猜测写Excel。I比例遵守既有计划公式，无定义标待确认，不自创比例或覆盖公式；H写待验收不能视为G0已完成。更新采用新版本和差异记录，两种格式无法保持一致则暂停发布。本轮不更新任何计划。

每次交接填写版本/有效状态、Git/未提交、实际做了什么、证据/异常、未测、下一唯一获授权WBS；未授权下一任务写NONE并停在审查。恢复执行先重核本机状态，不按旧上下文自动安装/启动/推送。
