## 4. 第三关：两份配置的实际备份及解密恢复演练

仅对**本轮新授权**的配置实施：

- 在已验证受限目录下建立单独的保密备份区，配置内容由本机加密后保存；加密文件不进入`source-safe.zip`。
- 在受控临时恢复目录中，从**实际加密备份**解密并逐份计算SHA256，与本机源配置文件计算的SHA256比较。记录仅包含路径、hash、字节数、保护方式、结果（PASS/FAIL），不保存配置明文到上报材料。

- 如果无法安全完成任一配置的恢复，报告`PARTIAL_BACKUP_ONLY`并停止，不进入Git。

注意：项目外备份与原项目同一个物理磁盘，只能证明同盘恢复，不是异盘/异机灾备。视频、数据库、`storage`、`output`、模型权重、外部盘依然不在本轮备份范围，必须明确列出未覆盖。
