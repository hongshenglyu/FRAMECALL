## 2. 从可共享源码补丁实际核到的改造

1. `TaskService`不再同类内部`@Async`调用，通过新`AnalysisDispatcher`提交有界进程内后台工作；`TaskAttempt`、`TaskAttemptRepository`持久化运行尝试；`AnalysisTaskRepository`加任务行悲观锁；任务分配/状态更新为独立短事务，AI网络调用移出长事务。
2. `TaskAttempt`含UUID、taskId、状态、active、创建/开始/完成时间、ownerInstance和错误码；任务、事件增加可空attempt关联。按任务锁内分配attempt；同一task当前只允许一个活动尝试，非法重试返回409；不提供Idempotency-Key响应重放缓存，也不跨上传任务去重。
3. `InternalCallbackService`将回调grant关联attempt；`AiClient`将输出根限定到相应attempt目录；后端在状态写入时再次比较当前attempt；拒绝旧回调和迟到执行结果。
4. 重试不再删除既有事件；本轮有历史Review及媒体未覆盖测试。但旧新事件当前仍可能混合展示，清理及报告语义不属于本轮。
5. 断联/超时等结果不确定时记录`AI_OUTCOME_UNKNOWN`、`RECOVERY_REQUIRED`并**保留active=true安全占位**。这里`active`不必表示Java线程仍运行，而是人工排险前阻止自动重试。重启处理仅隔离遗留记录，不做自动重放。
