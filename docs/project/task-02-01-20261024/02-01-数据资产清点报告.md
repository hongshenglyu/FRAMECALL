# 02-01 数据资产清点报告

边界仅为项目六个既有素材目录、storage，以及检查是否存在的data、data-manifest。后两者本轮在项目根不存在；这不代表外部不存在。枚举不跟随Windows重解析点；详细范围及跳过项见scope-evidence.json。未读业务数据库、配置原值、非项目私人目录；未安装依赖、联网传输或启动服务。

63个MP4文件全部读出视频轨元数据，首帧解码63成功、0失败，范围5.70—77.97秒。PyAV使用本机已有依赖；H.264为31份、HEVC为32份。首帧检查每文件25秒超时，不落盘帧、不全片解码，不能证明全片无损、音画同步或尾部可播放。视频轨数量也不能证明实际单机位，view统一UNVERIFIED。

六个已知素材目录仍为23份：明显不是手球2、明显不是越位1、明显不是争抢5、手球5、越位5、争抢5。这里只保持目录标签用于来源位置核对，未裁定接触/犯规内容，未执行02-02专项分类。其余40份位于storage/uploads，均为短文件。20份文件名含demo-sample且元数据相同、各5.7秒；文件名不足以证明内容为合成或权利来源，因此仅标演示命名线索，不纳入完整比赛。

旧审计的23份视频轨头时长总和本轮复测为770.723333秒，与约770.723333秒一致。PyAV按视频流有效时长得768.706667秒；二者时基/编辑偏移口径不同，均保存在video-probes.json及video-assets.csv，不把差值写成素材丢失。23份编码时间表平均FPS为30共17、60共5、约27.124563共1，不固定25fps。后者stts有47条时间记录，提示时间间隔变化；未全片检查PTS/VFR。fps字段是实文件轨道平均值，不代表每个瞬间恒定帧率。显示尺寸/编码尺寸和旋转效果未全面视觉核验。

去重采用大小、视频流时长、有理平均FPS、分辨率分组，共24组；组内相同只表示可能副本，没有全量媒体SHA或逐字节比较，故精确独立素材数未知。没有任何组被认定为独立完整比赛。本机63文件均为已知短素材、上传短片或演示命名文件；未发现可据以认定完整比赛的文件/分段映射。比赛集合由用户待提供的外部库存决定，实际数量未知。

逐文件清单另存video-assets.csv（ASSET编号不冒充matchId）。matches-manifest.csv仅列必需表头、0条数据，原因是尚无可识别独立完整比赛。两项赛事放在event-evidence.json，不为“40余场”造40行占位；亦不把短片强配到E01/E02。
