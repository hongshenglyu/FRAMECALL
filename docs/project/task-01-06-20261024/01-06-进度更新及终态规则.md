# 进度及HTTP语义

- 阶段顺序：EXTRACTING→DETECTING→TRACKING→EVENT_ANALYSIS→COMPLETED；QUEUED/RUNNING为回调前状态。阶段和百分比必须同时不倒退，跳到更晚阶段但百分比降低仍409。
- 有效重复相同阶段/百分比200但不save，updatedAt不变。乱序409，阶段/百分比非法400，grant错误或已撤销401，仍有效格式/授权但旧attempt409。服务内部再次校验参数，不能仅靠DTO。
- 当前attempt仅RUNNING接收；CANCEL_REQUESTED、CANCELLED、SUCCEEDED、FAILED及隔离一律409，不覆盖取消错误码或进度。旧01-03兼容的null grant/null current仅允许legacy PENDING，不分配attempt、不写结果或成功。
- 回调COMPLETED/100限为99；最终成功只能由结果事务写SUCCEEDED和100。Task.status是业务终态依据，进度阶段COMPLETED仅是通知。原直接Java→FastAPI→Spring legacy测试由100调整99，Task仍PENDING；真实调度链最终仍SUCCEEDED/100。
- 排队未启动取消200/CANCELLED，无远端调用；运行取消202/CANCEL_REQUESTED，重复202不重发；双路完成后200/CANCELLED。已成功/失败取消409，已取消重复200。远端503/未知不回滚已提交的逻辑取消屏障，错误码在任务响应中可见，202不能当已取消完成。
- cancelOutcome为SENDING/ACCEPTED/REJECTED/UNKNOWN；executionFinished只表示本地分析调用已结束（或未执行），不单独证明远端停止；任何未知错误仍覆盖释放条件。UNKNOWN、AI_OUTCOME_UNKNOWN、RECOVERY_REQUIRED保持active。
- 取消连接超时5秒；取消读超时默认5秒、可配置50～30000毫秒，测试400毫秒。原分析默认读超时两小时，测试固定竞态10秒/未知350毫秒；所有网络调用事务外，无模型决策重试。
