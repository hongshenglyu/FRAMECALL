# 兼容与迁移

旧API保留，任务和事件响应分别增加可空attemptId；PENDING/RUNNING/SUCCEEDED/FAILED/CANCELLED枚举不新增。上传响应沿用原快照，立即读取任务详情可获取已分配attempt；前端轮询无需修改。重试非法状态409，容量拒绝503，权限保持401/404；没有Idempotency-Key缓存，保证范围为同task一个活动attempt。

旧事件/复核和媒体不删除；新事件含attemptId、产物位于独立子目录。列表暂显示各轮事件，历史分组/报告选择/删除留给01-07。TaskAttempt使用标量taskId，删除任务不级联attempt；孤立审计行后续治理。

migration-h2.sql已在两套全新内存H2中验证空表及既有合成记录增量迁移、旧行保留、主键冲突。当前应用仍使用既有Hibernate建表策略，本轮无自动迁移框架。migration-mysql-review-only.sql仅审查草案，未连接/执行MySQL，不承诺数据库时间精度、版本及锁行为与H2一致。

部署前停止旧Java和AI工作、备份并验证可恢复、核实实际Schema与时区/命名/DDL策略，再审查脚本；不得在线热迁移或运行两业务实例。历史current_attempt_id和attempt_id保持NULL，不伪造历史。旧PENDING/RUNNING须人工核实，不能自动重放；01-04外部强秘密配置仍必需。
