## 事件定义与时间

1. 以一次连续争抢为一个事件。记录可见的争抢开始和连续争抢结束；同次争抢中的多次接触合为一个事件。双方明确脱离、后来重新争抢时新增另一条标注，不把两个过程并入一次修订。
2. 只有画面确实可见身体接触，才记录首次可见接触帧。人物框重叠、距离小、速度突变或候选峰值都不能代替实际观察。算法峰值不是首次接触时间。
3. 接触可见性选择：`VISIBLE_CONTACT`可见身体接触、`NO_VISIBLE_CONTACT`未见身体接触、`INSUFFICIENT_VIEW`画面不足。无接触或接触无法判断时，首次接触时间为空，不能用0、窗口中点或算法峰值占位。
4. “画面过程”区分争抢、正常接近、未见争抢、无法确定。无接触争抢应由人工选择“争抢＋未见身体接触”，仍需记录争抢起止。整段“正常接近＋未见身体接触”可将三个时间都留空，作为片段级负样本提交；“未见争抢”也无需编造起止。未见接触不自动等于未见争抢，过程类型仍由人工选择。
5. 图像遮挡、远端小人、ID混淆和窗口截断都应在备注说明。无法确定边界时留空并先存草稿，补看上下文后再提交，不强行把片段边缘认作事件开始/结束。
6. 时间采用原片PTS。播放器时间由该片段首帧PTS偏移映射到实际源帧；逐帧按钮沿真实PTS序列移动，禁止固定25FPS推算。预览帧和素材区间只是来源定位，不是人工事件边界。

## 在现有系统中操作

1. 使用本人被授权的账户登录工作台，打开“P5待人工试标”任务。未导入时，在原有导入入口选择提取目录中的bundle.json及媒体。
2. 完整查看素材，必要时全屏、慢放及逐帧检查。打开“原始接触标注”，人工选择过程类型与接触可见性；不继承算法评分或旧复核结论。
3. 在实际画面上暂停，分别点击开始、首次接触、结束的“记录当前源帧”。允许清空未知字段；缺少视频或PTS映射时不能自动填值。
4. 一段素材有多个独立争抢时使用“新增另一段争抢”。同一争抢需要改正时选择已有记录，再保存新修订；旧修订不覆盖。
5. 未完成时保存草稿。实际查看并核对后，由标注人自行勾选确认，再提交原始标注待复核。重新打开自己的草稿会恢复已保存的确认状态；新记录、其他人的记录和已提交版本的修订不会自动勾选。提交条件不齐时，表单会显示原因，点击提交也会提示具体缺项。系统从登录账户记录标注人，Codex不代替人工确认。
6. 裁判复核另选一条已提交人工标注的具体修订版本，保存接触可见性结论及备注。原始标注和复核记录分开保存，可以存在不同判断；系统不改写原始标签，不自动判犯规。
7. 用“导出试标记录JSON”导出当前全部素材、原始修订和复核结论。草稿和FUNCTION_TEST功能记录不计为已完成人工标注，P5提交也不自动成为正式数据集真值。

## 保存与修订合同

活动格式为`framecall.contact-annotations.v1`。每个素材保留source中的matchId、partId、segmentId与赛事相对路径，sourceFrameBounds保留首尾源PTS及timeBase。原始标注的annotationKey区分不同争抢，revision区分同一争抢的修订。

每次修订保留：过程类型、争抢起止、首次接触、三处实际源帧的PTS/timeBase、接触可见性、真实登录标注人、草稿/提交状态、备注与创建时间。每个复核记录单独引用annotationRevisionId，保留裁判账户、结论、备注和复核修订号。导出中的annotations与reviews始终分开。

选择已有草稿后，可点击“删除当前草稿”并确认。删除只撤销该条记录尚未提交的草稿版本，不影响之前已提交的标注和裁判复核。撤销版本保留原文与discardedAt，显示在历史中，退出活动列表且不参与完成统计；后续修订序号不重复使用。

新保存记录以observationScope区分CLIP（起止均为空的片段级记录）和EVENT（记录了事件边界），observedSourceRange保留该素材真实首尾帧用于回溯，不填入事件起止或首次接触时间。原有记录不批量改写；初始准备数量见上文，开始人工操作后的进度以系统实时导出为准。

首次接触为空是有效信息；未标注、未见接触、画面不足是不同状态。初始16段的时间、可见性及标注人均为空，不能因为有MP4或算法候选就计为人工观察。

## 独立裁判复核准备

1. 管理员在“用户管理”为实际复核人创建本人账号，角色选择“裁判”。账号名称不能代替实际身份与裁判资质确认。截至本轮核查没有启用的REFEREE账号，尚未分配真实复核人。
2. 管理员进入已有16段任务，选择“分配另一位裁判的账号”，点击“保存裁判分配”。复用视频已有assignedTo权限；可清空分配撤回访问。当前一次分配一个账号，不新建标注平台或复制原任务。
3. 实际裁判用本人账号登录，打开被分配的任务，观看视频，选择对应的原始标注修订后自行填写结论、原因及备注。页面不会代入其他账号保存的复核意见；自己的已有复核可以继续修订。
4. 原始标注与复核分别保存。被分配裁判可读取真实素材与标注、追加复核，不允许修订其他人的annotationKey；管理员仍沿用既有管理权限。未被授权账号无法读取该任务或媒体。
5. 导出复核增加reviewerId及differentAccountFromAnnotator，界面区分同账号自查与其他账号复核。该字段只证明账号不同，不自动证明不同自然人或专业资质；确认复核人身份及过程后，才能计为独立裁判复核。同账号16条自查继续保留，独立裁判复核仍为0，不自动变成正式真值。

P5-S05目前记录为“正常接近＋可见身体接触”，起止638.397078—641.397078秒，首次可见接触638.997078秒，均对应有效源PTS，符合现有字段规则。过程类型与可见接触可并存，不判定为无效标注；若实际为抢球争抢，请由原标注人重新观看确认是否需要改为“争抢”，并追加修订。本轮未修改该判断。

## 后续整场筛选与划分

[full-match-screening.json](data/full-match-screening.json)列出8个后续筛选候选，目标是取得6—10场确证完整且可用的比赛。当前候选仍为UNVERIFIED_FULLNESS，确认完整0场；35场未知完整性不能直接计成完整比赛。时长、无缺号、首尾抽帧只能作为待核查依据。

逐场核对官方比赛身份、开终场覆盖、段间衔接、全程可解码情况与来源许可。按matchId统一所有Part的归属。当前P1—P5已用比赛固定为开发用途；清单整体暂拟4开发/2验证/2测试保留位（含当前已用开发比赛），完整性与标注条件齐备后再冻结。测试比赛不用于阈值调试，不能按分段拆入其他集合。本轮未读取保留测试比赛的视频，也未启动整场正式实验。
